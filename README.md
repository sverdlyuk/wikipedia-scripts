# wikipedia-scripts
red-links.js — знаходить і пропонує замінити англомовні червоні посилання українськими відповідниками.

refresh-interlanguage-links.js — оновлює кеш мовних версій статті, щоб відобразилися нові міжмовні посилання.

Для встановлення потрібно додати скрипт на сторінку користувача `https://uk.wikipedia.org/wiki/Користувач:XXXXX/common.js`
