# wikipedia-scripts
red-links.js — знаходить і пропонує замінити англомовні червоні посилання українськими відповідниками. Кнопка 🔧 Червоні → укр з'являється в редакторі коду

<img width="1217" height="543" alt="2026-11-03_16 14 55" src="https://github.com/user-attachments/assets/25b337d2-b290-46fb-9163-f2d2d1fcc56b" />


refresh-interlanguage-links.js — оновлює кеш мовних версій статті, щоб відобразилися нові міжмовні посилання. Потрібен для вирішення проблеми, коли після приєднання статті у вікіданих в інших мовах не відображається стаття. Якщо у вас цієї проблеми немає - скрипт не потрібен. Працює аналогічно ручній чистці кешу, `?action=purge` лише автоматично і для усіх мовних посилань. Кнопка в панелі інструментів має назву оновити кеш міжмовних посилань.
